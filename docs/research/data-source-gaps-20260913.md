# 数据源增强与剩余缺口（2026-09-13）

Qagent 已有多源日线、分钟获取、历史证据和基本面能力。本轮最有价值的补强是把 Relay 的返回整理成可复核的研究输入，并核验实际覆盖和时效；接口目录变大本身不能证明选股、持仓更新或生产可靠性改善。

## 已有能力与证据边界

- 默认行情工厂已有 FreeCN、TickFlow 日线后备、可选 Fuyao 日线/快照和缓存；FreeCN 日线使用 AKShare/BaoStock 等来源，分钟 getter 使用 Sina。此为[当前实现](../../backend/qagent/providers/factory.py)，不代表本轮重新核验了云端各源健康。
- [历史证据提供者](../../backend/qagent/historical_evidence/providers.py) 已覆盖历史股票池、基准、公司行动、行业和交易状态，并有 BaoStock 与保守 PIT 基本面路径。不能把 Relay 尚未适配的能力描述成整个系统缺失，也不能据代码存在宣称历史覆盖完整。
- [Relay 研究入口](../../backend/qagent/providers/tushare_relay_research.py) 已有明确锚点的日线/因子配对，以及带估值日、财报期、公告日的当前基本面快照。它显式拒绝历史 PIT 请求，未接入默认行情或策略工厂，研究开关也不会自动改变既有 job。
- [此前正式验证](tushare-relay-integration-20260913.md)累计尝试 18 种 API：11 项获得非空且通过对应检查的返回，其中 daily/adj_factor 为业务单样本通过，其余 9 项仅结构通过；另有 rt_min 在周日返回上周五一行。历史分钟出现 202 pending/503，尚未获得可验样本；这不能概括为所有分钟接口永久不可用。253 项 probe 的 HTTP 200/no_rows 也不是业务验收。

## 本轮实施及验收

新增 [分钟研究归一化](../../backend/qagent/providers/tushare_relay_minutes.py)：每次显式选择 rt_min/stk_mins/a_share_mins 之一、限定单股单日一页，校验身份、日期、上海时区、交易时间、OHLC 和重复时间，并保留来源、最新行情时间及采样上限。`frequency_verified=false`、`coverage=sample_full_session_unknown` 和未确认成交量单位明确保留；rt_min 的日期只校验返回，不能把近期端点当作历史归档接口。

新增 [统一研究采集入口](../../scripts/collect_tushare_research.py)，将单股单日配对日线、可选当前基本面及分钟输出为 stdout JSON；不连接数据库或写账本。各部分独立报告失败，安全的 HTTP 状态码可以保留；基本面以采集当天为 as-of，不随 `--date` 回标。运行示例（凭据预先放入 `QAGENT_TUSHARE_RELAY_KEY` 环境变量）：

```sh
python scripts/collect_tushare_research.py --symbol CN:000001 --date 2026-09-11 --fundamentals --minute-api rt_min
```

主任务本轮真实执行上述请求退出 1、`incomplete`：日线 `http_error`、0 行，基本面 `no_rows` 且含 `transport_error`，分钟 `transport_error`、0 行。这是本次取数未完成的证据，不能覆盖此前日线/因子/基本面单样本成功，也不能推断供应方永久不可用。

随后主任务以 15 秒超时、零重试定向复查：daily 为 `transport_error`、无 HTTP 状态；rt_min 经本轮归一化器成功返回 1 行，最新时间 `2026-09-11 15:00:00+08:00`，`realtime_freshness=not_current_session`。这补齐了分钟归一化的真实单样本证据；请求当天为周日，成功校验上周五一行不等于当前实时性、完整区间覆盖或 CLI 全链路成功。

本地分钟专项 32 项、采集入口初版专项 12 项；主任务初次相关回归 132 passed（2.49 秒），追加 HTTP 状态输出后最终相关回归 **133 passed、1 项既有 warning（2.03 秒）**，Ruff/diff 检查通过。本轮未重跑全量，前轮 2171 passed 保留在接入报告，不作为本轮全量验收。冻结研究摘要仍为 `309625c7be262e81bc22c35f40f563f7c497d78252ac6b4dfabd0e168642c848`。已实现并完成上述本地测试，未 commit、未 push、未部署、未启用默认源；G3/G7 仍未完成，G1/G2 门槛及旧测试/实测快照保留。
