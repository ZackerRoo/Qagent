# G2 双模型稳健共识候选（2026-09-13）

本轮在 G2 下新增一个隔离选股假设：优先选择两条已有模型都排在前面的股票，降低名单对是否移除风险预测输入的依赖。它直接生成候选名单，不需要新数据源或等待收益标签。

## 复用与固定规则

复用已有 ready G2 signal 和 `compare_g2_selections.validate_signal` 的摘要、配对集合、分数及排名校验，以及行业分布诊断。现有研究已经有行业/市值中性化、种子预测均值和 V4 多通道配额，不重复实现它们。

新入口 `scripts/rank_g2_consensus.py` 固定按以下顺序升序排序：两模型较差名次、两模型名次等权均值、股票 ID。例如 (2,2) 排在 (1,5) 前。等权均值仅用于较差名次相同时破平；这不是收益优化或置信概率。规则没有可调参，不读取收益标签，不训练模型。

输出完整排序、Top5/Top10/前10%名单、各模型原始名次/分数、名次分歧、相对两模型进出名单及行业分布。输入摘要、两份脚本摘要、协议摘要和产物摘要可追溯。仅使用标准库，输出用同目录临时文件和独占硬链接发布，拒绝覆盖已有文件。

```sh
python scripts/rank_g2_consensus.py --signal /path/to/ready-signal.json --output /path/to/new-candidate.json
```

专项测试覆盖双侧稳健优先、均值/ID破平、输入顺序不变、相同模型复现基线、无收益依赖、无输入修改、非法信号拒绝、小集合及未知行业、无推理依赖 CLI、摘要和原子不覆盖输出。实现子任务运行新旧选股脚本相关测试 **23 passed（0.26 秒）**，Ruff 通过；主任务最终 review 和真实信号运行待补录。

这是新的离线研究候选，未改动两条冻结 G2 变体、冻结模型、既有信号、生产排名、模拟账户规则或自然采集调度。不将历史信号上的新增名单计作已预注册前向结果；两变体同源且相关，不是独立模型投票，也不证明置信度提高。Minimax 可能舍弃仅被单一模型识别的高超额收益股票，不保证更优。净收益、回撤、换手与可执行性仍未验证，未知行业作为单独诊断桶。本轮不新增目标编号，不提升 G2 完成状态。
